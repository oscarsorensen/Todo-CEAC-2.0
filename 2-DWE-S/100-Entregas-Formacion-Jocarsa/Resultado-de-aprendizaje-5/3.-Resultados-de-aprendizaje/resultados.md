# RA5 - Develops web applications by identifying and applying mechanisms to separate presentation code from business logic.

## a) The advantages of separating business logic from the presentation aspects of the application have been identified.


## b) Mechanisms and frameworks that allow this separation, and their main characteristics, have been analysed and used.


## c) Server objects and controls have been used to generate the visual appearance of the web application on the client.


## d) Dynamically generated forms have been used to respond to the events of the web application.


## e) The parameters relating to the configuration of the web application have been identified and applied.


## f) Web applications with state maintenance and separation of business logic have been written.


## g) The principles and design patterns of object-oriented programming have been applied.


## h) The code has been tested and documented.
