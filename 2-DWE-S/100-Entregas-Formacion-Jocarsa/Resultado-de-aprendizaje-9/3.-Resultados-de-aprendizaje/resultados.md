# RA9 - Develops hybrid web applications by selecting and using technologies, server frameworks and heterogeneous information repositories.

## a) The advantages of code reuse and of making use of existing information have been recognised.


## b) Technologies and frameworks applicable to creating hybrid web applications have been identified.


## c) A web application that retrieves and processes existing information repositories has been created.


## d) Specific repositories have been created from information existing in information stores.


## e) Code libraries and frameworks have been used to add specific functionality to a web application.


## f) Web services and applications have been programmed using information and code generated by third parties as a base.


## g) Code libraries related to Big Data and business intelligence have been analysed and used, to add data analysis and intelligence from repositories.


## h) The generated applications have been tested, debugged and documented.
