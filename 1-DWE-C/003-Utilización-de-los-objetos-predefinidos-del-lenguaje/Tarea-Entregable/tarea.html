Tarea Tema 3: Contador de visitas Create a page that greets the visitor by name and counts how many times they've visited, saving the data in the browser. Requirements: If no name is stored in localStorage, ask the user to enter one. The first letter must be capitalized and the rest lowercase. If the field is left blank or the user cancels, the visitor will be referred to as “Guest.” If a name is already stored, ask: “Are you [storedUser]?” If the user answers “no,” clear the data and ask for the name again. Count the visits. Every 5 visits, congratulate the user. Display the greeting and the number of visits on the page using `createElement` and `textContent`: “Hello, Elena. This is your 3rd visit.” Display the date and time of the visit in the format dd/mm/yyyy hh:mm.
