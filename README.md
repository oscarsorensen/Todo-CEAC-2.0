# DAW Year 2 — CEAC Coursework

Second year of Desarrollo de Aplicaciones Web at CEAC, Valencia.

Like [Year One](https://github.com/oscarsorensen/Todo-CEAC-1.0), this repo is not
a portfolio — it's a working archive of everything built and learned during the
course. Quality varies by intent: some folders are polished exercises, some are
raw explorations, some are exam submissions.
