Accesibilidad

Un dojo es para todo el mundo. La web también.

Objetivo

Esta web busca cumplir el nivel AA de las WCAG 2.2 del W3C.

Qué hemos hecho

  • Contraste mínimo de 4,5:1 en todo el texto (comprobado en la guía de estilo).
  • Todo se maneja con teclado, con foco visible en oro y un enlace para saltar al contenido.
  • Las ilustraciones animadas tienen botón de pausa y se quedan quietas si pides menos movimiento.
  • Las ilustraciones con contenido tienen descripción para lectores de pantalla; las decorativas se ocultan.
  • Formularios con etiquetas, errores explicados en texto y resumen de errores al enviar.
  • Ajustes de lectura: texto más grande, menos movimiento y alto contraste.
  • HTML semántico: un h1 por página, regiones, tablas con encabezados.

Cómo lo comprobamos

  • Revisión automática con pa11y (estándar WCAG2AA) en todas las páginas.
  • Lighthouse en Chrome (accesibilidad, rendimiento, buenas prácticas y SEO).
  • Prueba manual solo con teclado y con VoiceOver en macOS.
  • Prueba en móvil a 375 px de ancho y con zoom al 200 %.

Limitaciones conocidas

  • Las descripciones de las ilustraciones las escribimos nosotros; pueden mejorar.
  • El formulario no envía datos: es un proyecto de clase.

¿Algo no funciona? Escríbenos a hola@osudojo.example. Osu.
